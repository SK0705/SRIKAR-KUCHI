## ✨ Architectural Features

1. **Horizontal 3D Glassmorphism Executive Pass**:
   - Landscape aspect ratio (540px × 330px) formatted as an executive access badge.
   - **Front Face**: Displays `ID.png` photo in a cyan glowing bezel frame, barcode SVG, gold EMV smart chip, name, BCA CGPA 7.95, and CA Inter credentials.
   - **Interactive Smart Chip**: Tapping the gold chip opens a live system diagnostic HUD (`SYS_LOAD: 12.4%`, `ACTIVE_PRODUCTS: 4`, `FINANCIAL_ACCURACY: 99.8%`).
   - **Back Face**: Horizontal 3D flip physics revealing scannable QR code, SHA-256 verification hash, LinkedIn link, direct email, and phone trigger.

2. **Real-time WebGL / Canvas Particle Network**:
   - 60fps cursor forcefield particle mesh background with interactive node connections and ambient glow grid.

3. **Command Palette (`Cmd + K` / `Ctrl + K`)**:
   - Keyboard-driven modal for instant section navigation, email copying, and social links.

4. **Web Audio API Cyber Sound Synthesizer**:
   - Pure browser Web Audio API synth providing retro-futuristic sound effects for clicks, badge flips, and chip taps. Includes navbar mute/unmute toggle.

5. **Floating Social Sidebar**:
   - Fixed left-edge glass social bar keeping LinkedIn, GitHub, Email, and Phone accessible from any scroll position.

## ⚙️ Running Locally

Run the static web application locally using any standard HTTP server:

**Using Python:**
```bash
python -m http.server 8001
```

**Using Node.js (http-server):**
```bash
npx http-server -p 8001
```

Navigate to `http://localhost:8001` in your browser.
